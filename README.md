## Project Description
This is a Login and Registration system built in Java using NetBeans. It allows a user to register with validation for username, password and cellphone number, and then login to the system.

## Features - Part 1
- User Registration with validations
- Username must contain _ and be max 5 characters
- Password must have 8 characters, capital letter, number and special character
- Cellphone must start with +27 and be 12 characters
- Login functionality
- Returns login status messages

## How to Run
1. Open NetBeans
2. Open Project PROG5121_FA1
3. Run Login.java and Register.java
4. Run unit tests: Right-click project > Test

- Tests for registration, login, username validation, password validation, cellphone validation
